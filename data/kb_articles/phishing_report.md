# Suspicious Email / Phishing Report

Category: Security

Symptoms: Employee reports a suspicious email, suspects a phishing attempt, or clicked a link and is worried about compromise.

Resolution steps:
1. Treat as high priority. Do not close without a security team review.
2. Ask the employee not to click any further links or reply, and preserve the original message headers.
3. If a link was clicked or credentials entered, force an immediate password reset and review recent sign-in activity for the account.
4. Submit the sample to the security team's phishing analysis queue.
5. If confirmed malicious, block the sender domain and notify affected distribution lists.

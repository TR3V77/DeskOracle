# Application Crashing or Freezing

Category: Software

Symptoms: An application crashes on launch, freezes during use, or shows repeated error dialogs.

Resolution steps:
1. Check for pending application or OS updates and apply them.
2. Clear the application's local cache/temp files.
3. Reproduce the crash and collect the event log / crash dump for the ticket.
4. Try running the application in a clean user profile to rule out a corrupted local profile.
5. If crashes are widespread after a recent patch, escalate to the application owner and check for a known issue advisory.

# Monitor / Docking Station Issues

Category: Hardware

Symptoms: External monitor not detected, docking station not powering peripherals, display flickering.

Resolution steps:
1. Reseat the dock connection and try a different USB-C/Thunderbolt port.
2. Update docking station firmware and display drivers.
3. Test the monitor with a direct cable connection to isolate dock vs. monitor vs. cable fault.
4. Swap in a loaner dock if the issue persists to confirm hardware fault.
5. Order a replacement dock through the standard hardware request process if confirmed faulty.

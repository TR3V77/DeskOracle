# New System / Folder Access Request

Category: Account_Access

Symptoms: Employee needs access to a shared drive, internal application, or elevated permissions for a project.

Resolution steps:
1. Confirm the requester's manager has approved the access request (check the ticket for an approval attachment or reference number).
2. Identify the correct security group tied to the requested resource.
3. Add the employee to the group and confirm propagation (can take up to 30 minutes).
4. Log the access grant for the quarterly access-review audit.
5. Notify the employee once access is confirmed.

# Software Installation / License Request

Category: Software

Symptoms: Employee needs a new application installed, a license activation error, or a software update.

Resolution steps:
1. Confirm the software is on the approved enterprise catalog; if not, route to the software approval workflow.
2. Check available license seats in the license management console.
3. Push install via the enterprise software deployment tool, or provide self-service install instructions if the app is in the self-service portal.
4. For activation errors, confirm the employee is connected to VPN or on-site network so the license server is reachable.
5. Document the license assignment for compliance tracking.
